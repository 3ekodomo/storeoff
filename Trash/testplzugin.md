/README.md:
--------------------------------------------------------------------------------
 1 | # Zettel Notes ImgBB Plugin
 2 | 
 3 | This project is a standalone buildable version of the ImgBB Zettel Notes plugin.
 4 | 
 5 | ## GitHub Actions
 6 | 
 7 | Push the project to GitHub. The included workflow:
 8 | 
 9 | 1. Installs JDK 17.
10 | 2. Uses the included Gradle wrapper (Gradle 8.7).
11 | 3. Builds `:plugin-btn-imgbb:assembleRelease`.
12 | 4. Uploads the release APK as the `imgbb-plugin-release` workflow artifact.
13 | 
14 | No `local.properties`, signing key, external Zettel Notes source checkout, or local version catalog is required.
15 | 
16 | The plugin uses the official Zettel Notes Plugin API dependency `com.github.damionx7:Zettel-Notes-Plugin-Api:28`.
